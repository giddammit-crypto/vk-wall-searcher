## Что уже построено (risk-first, по §4 плана)

Прототип: [`game/tla/`](../game/tla/README.md) — уровень «Главный читальный зал»
из §3.1, чек-лист механик §3.2 закрыт **8 из 8**.

Риск-модули, которые план требовал строить первыми:

1. **Акустика** (§0.4B, §2.2) — волновой Dijkstra по тайлам с поглощением
   материалов, эхо купола с фантомной точкой-обманкой, дождь как «окно тишины».
2. **Зрение и FSM врагов** (§2.2) — конус + raycast-окклюзия стеллажами,
   память последней позиции, переходы patrol → investigate → hunt → lost,
   слух через выборку поля громкости (враги подписаны на сетку, не друг на друга).
3. **2D-свет** (§1.2) — три слоя (ambient → zone → dynamic), силуэтные тени от
   окклюдеров через destination-out + blur, свет как валюта: фонарь игрока
   повышает его заметность для Смотрителя.
