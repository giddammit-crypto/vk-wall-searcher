# Плагин WordPress «Каталог OPAC» (opac-catalog-search)

Модальное окно поиска по электронному каталогу **OPAC-Global** (БД 62, ЦГБ г. Владимира) —
функционал поиска по ОПАК из проекта `vk_wall_searcher_php`, оформленный как самостоятельный
плагин WordPress.

Возможности — те же, что на сайте AURORA:

* поиск библиографических записей (`opacfindd.FindView`) с каскадным fallback (FT-конъюнкция →
  фраза → TI-заглавие → инвентарный номер);
* экземпляры и наличие по всем 18 филиалам (`opacholdd.MoveCopies`) с адресами и телефонами;
* фильтр по филиалам (ЦГБ, ЦДБ, Филиал №4 «Доброе», ф1…ф16) и поиск по инвентарному номеру;
* обложки книг: ЛитРес → Яндекс Книги → OpenLibrary → Google Книги (серверный кэш 7 дней);
* пагинация (4 карточки на страницу), «быстрые» запросы, окно подробных сведений о книге;
* защита OPAC-сервера: гейткипер (mutex + пауза 350 мс), Circuit Breaker, Rate Limit,
  двухуровневое кэширование сессий и экземпляров.

## Требования

* WordPress 5.8+, PHP 7.1+ (полная совместимость с PHP 7.1, 7.2, 7.3, 7.4, 8.0, 8.1, 8.2, 8.3, 8.4, 8.5+), расширение cURL.
* Расширения mbstring/xml не обязательны — в коде есть полифиллы и собственный XML-парсер.
* Сервер должен иметь исходящий доступ к `https://opac.lib33.ru` и внешним API обложек.

## Установка

1. Скопируйте папку `opac-catalog-search` в `wp-content/plugins/`
   (или загрузите zip-архив: Плагины → Добавить новый → Загрузить плагин).
2. Активируйте плагин «Каталог OPAC — поиск по электронному каталогу ЦГБ».
3. Проверьте соединение: **Настройки → Каталог OPAC → «Проверить сессию OPAC»**.

Кэш пишется в `wp-content/uploads/opacwp-cache/` (при недоступности — в системный tmp).

## Как встроить каталог в меню и на сайт

Модальное окно открывается поверх страницы так же, как на сайте AURORA. Способы:

### 1. Автовставка пункта в меню (рекомендуется)

**Настройки → Каталог OPAC → «Меню для авто-вставки пункта»** — выберите локацию меню
(например, `main` или `primary`). В конец выбранного меню автоматически добавится пункт
«Каталог книг» с бейджем «OPAC». Название и бейдж настраиваются там же.

### 2. Произвольная ссылка в меню

Внешний вид → Меню → добавьте «Произвольную ссылку» с URL `#opac-catalog`
(подпись любая, например «📚 Каталог книг»). Плагин перехватывает клик по такой ссылке
и открывает модальное окно. Если такая ссылка уже есть в меню, автовставка (п. 1) не дублируется.

### 3. Шорткод

В странице, записи, виджете или Gutenberg-блоке «Шорткод»:

```
[opac_catalog]
[opac_catalog text="Найти книгу" badge="" icon="search"]
[opac_catalog_button text="Электронный каталог"]
```

Атрибуты: `text` — подпись кнопки, `badge` — метка-бейдж (пусто — скрыть),
`icon` — имя иконки Material Symbols, `class` — дополнительные CSS-классы.

### 4. Любая кнопка/ссылка с классом-триггером

К любому элементу темы добавьте класс `opac-open-trigger` (или ссылку `href="#opac-catalog")`:

```html
<button class="my-theme-button opac-open-trigger">Каталог книг</button>
```

### 5. Плавающая кнопка

**Настройки → Каталог OPAC → «Плавающая кнопка»** — круглая кнопка каталога
в правом нижнем углу на всех страницах сайта.

### Программный вызов

```js
window.OpacCatalog.open();          // открыть окно
window.OpacCatalog.open('Пушкин');  // открыть и сразу выполнить поиск
window.OpacCatalog.close();
```

## Настройки (Настройки → Каталог OPAC)

| Параметр | Описание |
|---|---|
| Базовый URL / логин / пароль / iddb | Подключение к OPAC-Global (`opac.exe` / `direct.exe`) |
| TTL сессии, кэш экземпляров, пауза между запросами | Экономика вызовов и защита CGI OPAC |
| Меню для авто-вставки, название пункта, бейдж | Встраивание в навигацию темы |
| Плавающая кнопка, обложки, ассеты, Material Symbols | Поведение на фронтенде |

Логин/пароль по умолчанию — те же, что в `api/opac.php` исходного проекта (`CGBRD`).
Спецификация протокола: `docs/OPAC_SPECIFICATION.md` в корне проекта.

## AJAX-эндпоинты (admin-ajax.php)

| action | Назначение | Основные параметры |
|---|---|---|
| `opac_search` | Поиск с обогащением экземплярами | `q`, `page`, `length`, `start`, `include_copies`, `cascade`, `branch`, `only_available`, `refresh` |
| `opac_copies` | Экземпляры по записи | `idbr` |
| `opac_cover` | Обложка книги | `title`, `author`, `isbn`, `source` |
| `opac_status` | Проверка сессии | `refresh` (только администратор) |

Ответы полностью совместим с форматом `api/opac.php` исходного проекта.

## Соответствие исходникам проекта

| Плагин | Источник |
|---|---|
| `includes/class-opac-gateway.php` | `api/opac.php` (префикс функций `opac_` → `opacwp_`, кэш в uploads, конфиг из опций WP) |
| `includes/class-opac-client.php` | `api/OpacClient.php` (сокращён до словаря сигл и сопоставителей филиалов) |
| `includes/class-opac-ajax.php` | Диспетчер `opac_handle_http_request()` на WP AJAX |
| `assets/js/opac-modal.js` | `src/opac_modal.js` (ES-модуль → standalone IIFE, API через admin-ajax) |
| `assets/css/opac-search.css` | `src/opac_search.css` + блок фолбэков переменных и триггеров |
| `branches_cache.json`, `assets/img/*` | Реестр филиалов и изображения (баннер, фолбэк обложки) |

```
│   ├── class-opac-client.php    # словарь сигл филиалов ЦГБ
│   └── class-opac-ajax.php      # AJAX-обработчики (search / copies / cover / status)
├── assets/
│   ├── css/opac-search.css      # стили модального окна
│   ├── js/opac-modal.js         # модальное окно (vanilla JS, без зависимостей)
│   └── img/                     # баннер каталога, фолбэк «НЕТ ОБЛОЖКИ»
├── branches_cache.json          # реестр 18 филиалов с адресами и телефонами
├── uninstall.php
└── readme.txt
```
