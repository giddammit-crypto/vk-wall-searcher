Модальное окно поиска по электронному каталогу OPAC-Global (БД 62, ЦГБ г. Владимира): наличие по 18 филиалам, обложки, фильтры.

== Description ==

Плагин переносит функционал поиска по каталогу ОПАК с сайта AURORA на любой WordPress-сайт:

* поиск изданий через OPAC-Global (`opacfindd.FindView`) с каскадным fallback;
* экземпляры и наличие по всем 18 библиотекам Владимира с адресами и телефонами;
* фильтр по филиалам (ЦГБ, ЦДБ, Филиал №4 «Доброе», ф1…ф16), поиск по инвентарному номеру;
* обложки книг: ЛитРес → Яндекс Книги → OpenLibrary → Google Книги;
* защита сервера каталога: гейткипер, Circuit Breaker, Rate Limit, кэширование.

Встраивание в меню WordPress: автовставка пункта в выбранную локацию меню, шорткод
`[opac_catalog]`, произвольная ссылка `#opac-catalog`, класс `.opac-open-trigger`
или плавающая кнопка. Открывается как модальное окно поверх страницы.

== Installation ==

1. Загрузите папку `opac-catalog-search` в `/wp-content/plugins/`.
2. Активируйте плагин в разделе «Плагины».
3. Настройте встраивание: Настройки → Каталог OPAC.
4. Проверьте сессию OPAC кнопкой «Проверить сессию OPAC».

== Frequently Asked Questions ==

= Как добавить пункт «Каталог книг» в меню? =

Выберите локацию меню в настройках плагина — пункт добавится автоматически. Либо
добавьте в меню произвольную ссылку с адресом `#opac-catalog`.

= Можно ли вставить кнопку в страницу? =

Да, шорткодом `[opac_catalog]`.
