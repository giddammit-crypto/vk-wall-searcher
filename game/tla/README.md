# THE LAST ARCHIVE — PoC-прототип «Главный читальный зал»

Реализация шага, который предписан производственным планом
[`docs/THE_LAST_ARCHIVE_PRODUCTION_PLAN.md`](../../docs/THE_LAST_ARCHIVE_PRODUCTION_PLAN.md):

> *Следующий документ после утверждения D1–D3: `docs/TLA_ART_BIBLE.md` (Фаза 1)
> и **прототип акустики (M2 risk-first)**.*

Прототип закрывает risk-first модули M0/M2 (акустика, зрение/FSM, свет) и весь
чек-лист механик PoC из §3.2 плана.

---

## Запуск

```bash
# из корня репозитория
python3 -m http.server 8410 --bind 0.0.0.0
# → http://localhost:8410/game/tla/
```

Никаких сборок и зависимостей: чистые ES-модули + Canvas2D.

## Тесты

```bash
node game/tla/test/core.test.mjs    # 67 проверок игровых систем (headless)
node game/tla/test/smoke.test.mjs   # 12 проверок браузерного слоя (стаб DOM/Canvas)
bash scripts/test_tla_prototype.sh  # node --check + оба набора разом
```

`core.test.mjs` импортирует боевые модули (`acoustics/ai/light/level/player/save`),
`smoke.test.mjs` поднимает минимальный стаб DOM и крутит реальный класс `Game`
из `js/main.js` — логика нигде не переписывается и не копируется.

## Чек-лист §3.2: где что лежит

| # | Механика | Статус | Где |
|---|---|---|---|
| 1 | Движение/присед/бег с разными профилями шума | ✅ | `core.js: MOVE`, `player.js: updatePlayer` |
| 2 | Акустическая сетка + UI-индикатор «насколько меня слышно» | ✅ | `acoustics.js: AcousticGrid`, `main.js: drawAudibilityOverlay`, HUD-метр |
| 3 | Конус зрения + окклюзия стеллажами + FSM (patrol/investigate/hunt/lost) | ✅ | `ai.js: Enemy`, `light.js: visibilityFor/losClear/shadowQuads` |
| 4 | Фонарь с батареей + честные тени от стеллажей | ✅ | `player.js: playerLightCone`, `render.js: _drawLighting` (destination-out + blur) |
| 5 | «Книга = топливо ИЛИ знание» с последствиями | ✅ | `player.js: readBook/burnBook`, `main.js: interact/case 'book'`, `endingText()` |
| 6 | Каталожный шкаф-укрытие + карточка каталога → план этажа | ✅ | `main.js: toggleHide/updateBreath`, `render.js: _drawMinimap` (зоны открываются карточками) |
| 7 | Дождь как «окно тишины» | ✅ | `acoustics.js: atten/thresholdBonus`, `main.js: updateWeather` |
| 8 | Сейв/лоад + возврат на базу с крафтом | ✅ | `save.js: createSaveSystem` (схема v1), `main.js: openCraft/craftTap/finishCraft`, `onCaught` → возврат на базу |

**8 из 8** — формальный порог Gate VS по механикам (≥7 из 8) закрыт.
Остальные критерии Gate VS (внешние плейтесты n≥6, ≥70% «хочу продолжить»,
20-минутные сессии) требуют живых людей и здесь не проверялись.

Дополнительно к чек-листу реализованы механики §0.4, на которых держится
дизайн: эхо купола с фантомной точкой (B), пыль в луче и споры с тепловым
следом (C), свет как валюта (E), крафт как миниигра тишины (§2.2).

## Управление

| Клавиша | Действие |
|---|---|
| WASD / стрелки | движение |
| Ctrl (или C) | красться |
| Shift | бег (тратит выносливость) |
| Мышь | направление взгляда и фонаря |
| F | фонарь (батарея) |
| E / ЛКМ | взаимодействие (книга, карточка, хлам, верстак, жаровня, шкаф) |

| H | спрятаться в каталожном шкафу (миниигра дыхания) |
| ПКМ | фонарь |
| Tab | личный архив и журнал |

## Архитектура

```
game/tla/
├── index.html              HUD, оверлеи (чтение/дыхание/крафт/архив/финал)
├── style.css               палитра §1.1 арт-библии
├── js/
│   ├── core.js             тайлы, материалы, палитра, MOVE, ENEMY_TYPES, математика
│   ├── acoustics.js        волновой Dijkstra по тайлам, эхо купола, дождь
│   ├── light.js            LOS, силуэтные квады теней, visibility, свет зон
│   ├── ai.js               A* + FSM (patrol/investigate/hunt/lost), слух/зрение/тепло
│   ├── level.js            уровень «Главный читальный зал»: 6 зон, проходы, пропы
│   ├── player.js           движение, профили шума, фонарь, инвентарь, книги, крафт-рецепты
│   ├── save.js             сейв-схема v1 (localStorage / память)
│   ├── render.js           top-down рендер: пол, тени, 3 слоя света, туман войны, миникарта
│   └── main.js             класс Game: цикл, погода, взаимодействия, HUD, финалы
└── test/
    ├── core.test.mjs       67 проверок систем
    └── smoke.test.mjs      12 проверок браузерного слоя
```

Модули `core/acoustics/light/ai/level/player/save` не трогают DOM — поэтому
тестируются в Node без браузера. `render.js` и `main.js` — браузерный слой.

## Модель акустики (риск-модуль №1)

`L(клетка) = I − Σ(шаг × 4.6 + поглощение материала)`, распространение —
Dijkstra по 8 соседям, стены (`abs = 99`) — полный экран.

| Профиль | Интенсивность | Слышно Читателю (порог 21) |
|---|---|---|
| Крадусь по ковру | 36 − 12 = 24 | ~0–1 тайл |
| Крадусь по паркету | 36 | ~2.4 тайла |
| Шаг по паркету | 62 | ~6.6 тайла |
| Шаг по ковру | 50 | ~4.7 тайла |
| Бег по паркету | 92 | ~11.5 тайла |
| Бег по паркету в дождь | 92 × 0.55 ≈ 51 | ~4.8 тайла |

Эхо купола: звук громче 55 в купольной зоне через 0.95 с порождает
«фантом» интенсивностью ×0.62 в зеркальной точке зала — враг уходит
проверять неверное место (§0.4B).

## Отклонения от плана и почему

1. **D2 (движок Godot 4.3+) не применён.** В рабочей среде нет Godot и GUI,
   поэтому risk-first прототип построен как web-PoC на Canvas2D: он проверяет
   ровно те же системы (акустика, LOS/FSM, 2D-свет с окклюдерами, fog of war,
   data-driven рецепты), но перенос в Godot остаётся отдельной задачей.
   Модули написаны так, чтобы переносились поштучно: `acoustics.js` →
   `AcousticGrid.gd`, `ai.js` → FSM-компоненты актёра, `level.js` → TileMap-ресурс.
2. **Нормалей нет** (пункт «нормали на 10 пропах» из §3.2 п.4): в пиксельной
   ревизии v1.1 плана нормали исключены («свет читается тинтом и тьмой»),
   поэтому вместо normal map сделаны честные силуэтные тени от окклюдеров.
3. **Звук — WebAudio-заглушки** (осцилляторы), не 60+ SFX-слоёв из M3.
4. **Внешние плейтесты не проводились** — метрики Gate VS по людям открыты.
