# Статистика групп ВК (VK Wall Searcher) — PHP/HTML Версия

> Разработка: **Амброзиев О.А.**  
> Полностью автономная веб-версия на **PHP 7.4+ / 8.x + HTML5/CSS3/JavaScript**.  
> Работает на **любом хостинге и веб-сервере** без необходимости устанавливать Python или сторонние библиотеки.

---

## 🚀 Варианты развертывания

### 1. На обычном веб-хостинге (Beget, Timeweb, Reg.ru, cPanel, ISPmanager и др.)

1. Загрузите файлы проекта в директорию вашего сайта (в корень или любую подпапку, например `public_html/` или `public_html/vk-wall-searcher/`):
   - `index.php` и `index.html`
   - папку `src/` (ядро приложения и модули)
   - папку `api/` (`vk-proxy.php`, `config.php` и др.)
   - папку `data/` (хранилище подписчиков и кэш)
   - `style.css`
   - `branches_cache.json`
   - `.htaccess`
   - `app.js` (монолитный бандл)

2. **Готово!** Никаких Node.js, Vite, npm или запуска файлов `.bat` / `.sh` на хостинге выполнять **НЕ НУЖНО**.
3. Откройте ваш сайт в браузере: `https://vash-sait.ru/` (или `https://vash-sait.ru/vk-wall-searcher/`). Всё работает сразу из коробки!
4. **Статический хостинг (без PHP / GitHub Pages):** проект автоматически переходит в автономный режим (JSONP) прямо в браузере.

---

### 2. Локальный запуск на компьютере (без установки Apache/Nginx)

Если у вас установлен PHP (версии 7.4 или выше):

- **Linux / macOS**:
  ```bash
  ./run_server.sh
  ```
  *(или вручную: `php -S localhost:8000`)*
- **Windows**:
  Дважды кликните по файлу `run_server.bat`  
  *(или в командной строке: `php -S localhost:8000`)*

Браузер откроется автоматически по адресу: `http://localhost:8000`.

---

### 3. На сервере с Nginx + PHP-FPM

Если вы используете Nginx, стандартная конфигурация сайта выглядит так:

```nginx
server {
    listen 80;
    server_name vk-searcher.example.com;
    root /var/www/vk_wall_searcher;
    index index.php index.html;

    charset utf-8;

    # Статические файлы отдаются напрямую
    location / {
        try_files $uri $uri/ /index.php?$args;
    }

    # Обработка PHP-скриптов
    location ~ \.php$ {
        include snippets/fastcgi-php.conf;
        fastcgi_pass unix:/run/php/php8.2-fpm.sock; # Укажите вашу версию PHP-FPM
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
        include fastcgi_params;
    }

    # Поддержка красивого URL /api/vk-proxy (если требуется)
    location = /api/vk-proxy {
        rewrite ^ /api/vk-proxy.php last;
    }
}
```

---

### 4. На сервере Apache / LiteSpeed / OpenServer / XAMPP

Файл `.htaccess` уже включен в проект. Он автоматически:
- Устанавливает кодировку UTF-8.
- Перенаправляет `/api/vk-proxy` на `api/vk-proxy.php`.
- Включает сжатие Gzip для ускорения загрузки скриптов и стилей.

Вам достаточно просто поместить файлы в папку `htdocs` или `domains/vash-sait/`.

## 🛠 Технические особенности PHP-версии

- **Полная автономность**: Не требует Composer, внешних вендоров или базы данных MySQL.
- **Встроенный Rate-Limiter**: Ограничивает частоту обращений к VK API (~3 запроса/сек) с помощью атомарной файловой блокировки в системной временной папке. Это защищает ваш токен от блокировки со стороны VK (`Too many requests per second`).
- **Универсальный сетевой транспорт**: Запросы выполняются через расширение `cURL`, а в случае его отсутствия на сервере автоматически задействуется нативный `file_get_contents` со стрим-контекстом.
- **Относительные пути**: Приложение полностью независимо от базового URL. Вы можете разместить его в корневом каталоге или глубоко во вложенной папке хостинга.
- **Полный функционал**:
  - Поиск записей по стене групп, пабликов, мероприятий и пользователей.
  - Поиск по всем филиалам библиотек Владимира (готовая база).
  - Фильтры по годам, месяцам, конкретным числам месяца, ключевым фразам.
  - Аналитика: лайки, репосты, просмотры, скорость сканирования.
  - Просмотр постов в виде интерактивных карточек и табличного отчета.
  - Экспорт: **Буфер обмена**, **CSV**, **JSON**, **Word (.doc / .docx)** и **автономный красивый HTML-отчёт**.
