### P0-2 — первое открытие шаблона давало пустой холст и `pageerror`
- **Симптом:** при первом клике по шаблону холст оставался пустым, в консоли
  `ReferenceError`.
- **Причины:** (1) в объектах `proApi` / `immediateProApi` ключ
  `getActiveBrushKind` объявлялся дважды — вторая стрелочная функция молча
  перекрывала первую, которая имела фолбэк `|| 'pencil'`; (2) в `editor.js`
  вызывалась `syncUI()` — такой функции в проекте нет.
- **Что сделано:** дубли ключей удалены, оставлена именованная функция с
  фолбэком (`figma_pro_tools.js`); оба вызова `syncUI()` заменены на реальный
  `onSelection()` (`editor.js`, ветки Alt+Arrow и стрелочного сдвига).
- **Проверка:** `npm run lint` (правила `no-dupe-keys`, `no-undef`) и
  `tests/lint.test.mjs`, который отдельно доказывает, что конфиг ловит такие
  дефекты на заведомо сломанном фрагменте.

### P1-4 — CORS прокси был открыт всем
- **Симптом:** любой сторонний сайт мог вызывать `ai_proxy.php` и расходовать
  квоту ИИ.
- **Что сделано:** вместо `Access-Control-Allow-Origin: *` — whitelist origins
  с эхо-возвратом совпавшего и `Vary: Origin`; добавлены `X-Content-Type-Options`
  и `Referrer-Policy`. Same-origin запросы редактора не затронуты (ACAO им не нужен).
- **Проверка:** `tests/static.test.mjs` («P1-4: прокси не раздаёт `*`»).

### P2-3 — доступность
- **Симптом:** 358 `<button>`, из них 21 с `aria-label`; у 14 правил CSS стоял
  `outline: none`, а `:focus-visible` описан лишь для 5 селекторов — Tab
  «проглатывал» фокус.
- **Что сделано:** новый `a11y.js` (подключён после `editor.js`, добавлен в
  пре-кэш SW): проставляет `aria-label` из `title`/`data-tooltip` для кнопок без
  видимого текста (220 кнопок имеют `title`), синхронизирует `aria-pressed` с
  классом `.is-active` через `MutationObserver`, добавляет `role="dialog"` +
  `aria-modal` и ловушку фокуса для `.modal-overlay`. В `style.css` — глобальное
  кольцо `:focus-visible` и поддержка `prefers-reduced-motion`.
  Скрипт аддитивен: id, классы и обработчики редактора не меняются.
- **Проверка:** `tests/a11y.test.mjs` (10 тестов).

### P2-5 — заголовки безопасности
- **Что сделано:** новый `vk-miniapp/poster/.htaccess` с CSP, `Referrer-Policy`,
  `Permissions-Policy`, `X-Content-Type-Options`, кэшированием вендора и запретом
  прямого доступа к `.ai_keys.php` (дублирован в корневом `.htaccess`).
  CSP ограничена каталогом редактора, чтобы не задеть другие приложения сайта.
- **Ограничения (честно):** `script-src` сохраняет `'unsafe-inline'` — в
  `index.html` 7 inline-скриптов, включая `document.write`-фолбэки CDN; уход от
  него требует nonce и выноса скриптов. `'wasm-unsafe-eval'` обязателен для
  WASM-вывода Transformers.js. `frame-ancestors` включает `vk.com` — иначе
  мини-апп не откроется во фрейме ВК. **CSP не проверялась в реальном браузере**
  (в песочнице его нет): для обкатки в файле оставлен закомментированный блок
  `Content-Security-Policy-Report-Only`.
- **Проверка:** `tests/static.test.mjs` — в том числе что CSP покрывает все
  внешние источники, которые реально встречаются в коде.

### P2-7 — маркетинг провайдера в списке моделей
- **Симптом:** в `CONFIG.MODELS` названия моделей содержали «(100% Free)».
- **Что сделано:** суффикс убран из 7 названий в `ai_elements.js`. Идентификаторы
  моделей не тронуты: `:free` в `id` — тег маршрутизации на стороне провайдера.
  Строка «100% БЕСПЛАТНО» в макете афиши (`editor.js`) — контент пользователя,
  она не изменялась.

### P2-2 — ESLint

  Первый же прогон нашёл два живых дефекта (см. P0-2).
- **Итог:** 0 ошибок, 10 косметических `no-useless-escape`.
- **Проверка:** `npm run lint`, `tests/lint.test.mjs`.
